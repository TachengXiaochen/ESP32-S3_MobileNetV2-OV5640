## 二、ESP32-S3 引脚分配

### 2.1 OV5640 摄像头 (DVP 8-bit 并行接口)

| 信号 | ESP32-S3 GPIO | 方向 | 说明 |
|------|:------------:|------|------|
| XCLK | **15** | OUT | 主时钟 20MHz |
| SIOD (SDA) | **4** | I/O | SCCB 数据 |
| SIOC (SCL) | **5** | OUT | SCCB 时钟 |
| D0 | **11** | IN | 数据 bit 0 |
| D1 | **9** | IN | 数据 bit 1 |
| D2 | **8** | IN | 数据 bit 2 |
| D3 | **10** | IN | 数据 bit 3 |
| D4 | **12** | IN | 数据 bit 4 |
| D5 | **18** | IN | 数据 bit 5 |
| D6 | **17** | IN | 数据 bit 6 |
| D7 | **16** | IN | 数据 bit 7 |
| VSYNC | **6** | IN | 帧同步 |
| HREF | **7** | IN | 行有效 |
| PCLK | **13** | IN | 像素时钟 |
| PWDN | NC (-1) | — | 不接，摄像头常供电 |
| RESET | NC (-1) | — | 不接 |

> **配置**: QVGA 320×240, JPEG 编码, fb_count=2 (PSRAM), XCLK 20MHz

### 2.2 MicroSD 卡 (SDMMC 1-bit 模式)

| 信号 | ESP32-S3 GPIO | 说明 |
|------|:------------:|------|
| CLK | **39** | 时钟 (20MHz, 驱动能力 3) |
| CMD | **38** | 命令/响应 (驱动能力 3) |
| D0 | **40** | 数据 0 (驱动能力 3) |
| CD/D3 | NC | 未使用 (1-bit 模式) |

> **配置**: FAT32, 1-bit SDMMC, `SDMMC_FREQ_DEFAULT` (20MHz), 内部上拉

### 2.3 WS2812 RGB LED

| 信号 | ESP32-S3 GPIO | 说明 |
|------|:------------:|------|
| DIN | **48** | 数据输入 (5V 供电) |

> **注意**: WS2812 需要 5V 供电，3.3V 驱动能力不足。建议使用外部 5V 电源。

### 2.4 通信接口

| 接口 | 用途 | TX (ESP32→) | RX (→ESP32) | 波特率 | 帧格式 |
|------|------|:-----------:|:-----------:|--------|--------|
| **UART0** | USB-TTL 调试 | GPIO43 | GPIO44 | 115200 8N1 | CLI 文本 |
| **UART1** | WS63 通信 ⭐ | **GPIO47** | **GPIO21** | 115200 8N1 | JSON Lines `\n` |
| **UART2** | L610 4G 模块 | GPIO19 | GPIO20 | 115200 8N1 | AT 指令 |

> **⚠️ 注意**: UART1 (WS63) 原使用 GPIO17/18，v3.4 迁移至 GPIO47/21 以解决与 OV5640 DVP D6/D5 冲突。

### 2.5 L610 4G 模块

| 信号 | ESP32-S3 GPIO | L610 引脚 | 方向 |
|------|:------------:|-----------|------|
| TX | **GPIO19** | RX | ESP32 → L610 |
| RX | **GPIO20** | TX | L610 → ESP32 |
| GND | GND | GND | 共地 |

> **配置**: 115200 8N1, AT 指令超时 5s, 重试 3 次  
> **供电**: 独立 5V/2A, 峰值电流可达 2A

## 三、WS63 引脚分配

### 3.1 通信接口

| 接口 | 用途 | WS63 GPIO | 对端 | 波特率 | 帧格式 |
|------|------|:---------:|------|--------|--------|
| **UART1** | ESP32-S3 通信 | TX=GPIO15, RX=GPIO16 | ESP32 GPIO47/21 | 115200 8N1 | JSON Lines `\n` |
| **UART2** | 串口屏通信 | TX=GPIO8(mode2), RX=GPIO7(mode2) | 淘晶驰 T1 | 115200 8N1 | CSV 帧 `@`/`#` `\r\n` |
| **SLE** | BS21E 标签通信 | 内置天线 | BS21E | — | NearLink 广播+连接 |
| **WiFi** | MQTT 云端 | 内置天线 2.4G | AP | — | TCP/IP |

### 3.2 WS63 ↔ 串口屏接线

| 信号 | WS63 GPIO | 屏端 | 方向 |
|------|:---------:|------|------|
| TX | **GPIO8** (mode2) | RX | WS63 → 屏 |
| RX | **GPIO7** (mode2) | TX | 屏 → WS63 |
| GND | GND | GND | 共地 |

> **屏端配置**: 淘晶驰 T1 4.3寸 480×272, `recmod=1` 主动解析, 3.3V TTL

## 五、供电要求

| 模块 | 电压 | 电流（峰值） | 建议 |
|------|:---:|:----------:|------|
| ESP32-S3 | 3.3V / 5V USB | ~500mA | USB-C 或稳定 5V |
| OV5640 | 3.3V / 1.8V (内部 LDO) | ~200mA | 摄像头排线供电 |
| WS2812 LED | **5V** | ~60mA/LED | 独立 5V，**勿用 3.3V** |
| MicroSD | 3.3V | ~100mA | 卡槽供电 |
| WS63 | 3.3V / 5V USB | ~300mA | USB-C |
| 淘晶驰 T1 | 5V | ~200mA | USB-C 或排线 |
| BS21E | 3V (纽扣电池) | ~10mA (广播) | CR2032 |
| L610 4G | 3.8V~4.2V | **2A (峰值)** | **独立电源** |

## 六、接线检查清单

- [ ] OV5640 排线方向正确，D0-D7 无虚焊
- [ ] WS63 UART1 接 ESP32 **GPIO47/21**，非 GPIO17/18
- [ ] MicroSD 卡已插入，格式化为 FAT32
- [ ] WS2812 LED 使用 **5V 外部供电**
- [ ] L610 使用 **独立 5V/2A 电源**
- [ ] 所有模块 GND 共地
- [ ] 串口屏 `recmod=1` 配置已生效
- [ ] 波特率全部 115200 8N1
